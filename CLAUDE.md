# AMC (Annual Maintenance Contracts)

This repo is empty and reserved for Crystal Group's AMC / service-contract app.
When code arrives, update this file with the stack, run and check commands,
and the Class 3 paths (contract value, billing, renewals, approvals, auth).

## LIVE SYSTEM — hard rules (apply from the first commit)
- Never push to `main`; open a PR. A human merges.
- Never connect to production data; never commit `.env*` or customer data.
- Money, approvals, permissions and sheet writers are Class 3: human-led,
  process-owner sign-off required.
